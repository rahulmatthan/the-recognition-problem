## Voice as the project's primary integrity

*Two short paragraphs. The thing that breaks first when an agent drafts a branch is the voice. A branch can be plot-correct, architecture-correct, and still be wrong because it doesn't sound like the same author on a different day. That's the test.*

> From `process/voice-profile.md`, §6 — the test:
> *Before signing off on a branch draft, the drafter asks: if I removed the chapter
> heading and the branch ID, would a reader who knows the canon recognise this
> as part of the same project, written by the same author on a different day?*

## What "voice" actually meant in practice

*A list of the things the voice profile codified:*

- *Beat-specific registers (Beat 1's quiet domestic, Beat 2's Lagos heat, Beat 6's Tbilisi elegiac, etc.)*
- *Recurring tics — the "which was" connector, triple cadence, cumulative "and" compounds, dialogue-with-colons, italic for foreign-language phrases*
- *The Tchaikovsky-register coda*
- *Anti-patterns — sentimentality, system-as-feeling in chapter prose, computer-register vocabulary in dialogue*

## The anti-patterns I learned by hitting them

*One paragraph each, briefly, on the anti-patterns I added to the profile during drafting:*

- *Tchaikovsky-overreach in codas (b8-tell)*
- *Verbatim canon repetition without variation (b1-walk)*
- *Tchaikovsky-coda narrating non-events (b5-tenyear, b5-fourth)*
- *Computer-register vocabulary in character dialogue (b6-visit)*
- *Narrating non-events in chapter prose (b9-restraint)*
